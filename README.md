# George Papadimitriou — Personal Academic Website

Personal academic website of George Papadimitriou, served by GitHub Pages.

## Contents
- `index.html`, `accessibility.html`: static pages
- `assets/site.css`, `assets/site.js`: styles and interactions (BibTeX, accessibility, navigation)
- `assets/img/`: profile, university/lab, awards, and research project images
- `assets/papers/`: local publication PDFs
- `assets/fonts/`: populated automatically during GitHub Actions build with Ubuntu webfonts

## Local preview
`python3 -m http.server 8000` and open http://localhost:8000/ .

No backend, database, or analytics platform is required.
